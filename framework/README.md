# Framework

This folder contains the conceptual and technical design documentation 
for the 3-tier Digital Mental Health NLP Pipeline.

## Contents
- `pipeline_design.md` — Full 3-tier system architecture and design rationale
- `clinical_rationale.md` — Evidence base for each pipeline design decision
- `governance_framework.md` — Data governance, consent, and ethics considerations
- `guardian_connection.md` — Link to the GUARDIAN multimodal prediction project

## Overview
The pipeline is designed for deployment within Singapore's school and 
community mental health settings, aligned with MOH's National Mental 
Health and Well-being Strategy and the four-tier care model.
