# Data

## ⚠️ Important Notice
This repository contains NO real patient data. All analysis uses 
publicly available research datasets or synthetic demonstration data only.

## Datasets Used

### 1. CNSocialDepress
- **Source:** Weibo (Chinese social media)
- **Size:** 44,178 posts from 233 users
- **Language:** Chinese (Simplified)
- **Access:** arXiv:2510.11233
- **Use in this project:** Depression risk detection EDA and classification demo

### 2. CLPsych 2024 Shared Task
- **Source:** Reddit
- **Language:** English
- **Access:** Request via CLPsych workshop (https://clpsych.org)
- **Use in this project:** Suicide risk evidence extraction benchmark

### 3. Synthetic Demo Data
- **File:** `sample_synthetic.csv`
- **Description:** Artificially generated text samples for pipeline demonstration
- **Note:** Does not represent real individuals

## Ethics
Any real-world deployment of this pipeline requires:
- IRB/ethics board approval
- Informed consent from participants
- Data minimisation and anonymisation
- Compliance with PDPA (Singapore) and relevant data protection regulations
